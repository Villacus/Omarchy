# Emuladores de Terminal en Omarchy

Configuraciones optimizadas para diversos emuladores de terminal soportados en el ecosistema Omarchy, todos configurados dentro de `~/.config/`.

## Emuladores Soportados

| Terminal | Ruta de Configuración | Notas |
|---|---|---|
| [Alacritty](https://alacritty.org/) | `alacritty/alacritty.toml` | Terminal rápida, acelerada por GPU. |
| [Kitty](https://sw.kovidgoyal.net/kitty/) | `kitty/kitty.conf` | Altamente configurable y con soporte para imágenes. |
| [Foot](https://codeberg.org/dnkl/foot) | `foot/foot.ini` | Ligera y optimizada para Wayland. |
| [Ghostty](https://ghostty.org/) | `ghostty/config` | Emulador de terminal moderno y rápido. |

## Estandarización

Aunque el emulador puede variar según la máquina o necesidad, las configuraciones intentan mantener la consistencia en el esquema de colores, fuentes y comportamiento del prompt (integrado mediante [[Starship|Starship Prompt]]).
