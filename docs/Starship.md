# Starship Prompt

[Starship](https://starship.rs/) es un prompt para terminal rápido, minimalista y altamente configurable, estructurado mediante el archivo `starship.toml` en la raíz de `~/.config`.

## Características Clave

- **Rendimiento**: Escrito en Rust, proporciona información instantánea del estado de la terminal sin retrasos perceptibles.
- **Contexto de Git**: Muestra de forma limpia el estado del repositorio actual (ramas, cambios pendientes, conflictos).
- **Indicadores de Entorno**: Muestra versiones activas de lenguajes de programación (Node.js, Python, Rust, etc.) solo cuando son relevantes en el directorio de trabajo.
- **Integración Homelab**: Compatible con las sesiones de [[Tmux|Tmux]] y los distintos [[Terminales|emuladores de terminal]].
